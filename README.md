# contracts

contracts holds the shared wire schemas: protobuf definitions and their generated Go types for the domains a shared host serves, so a caller and the serving host compile against one definition. Domains: anchor, audit, auth, billing, binding, device, domains, enrollment, executive, identity, inference, maintenance, monitoring, notify, options, plugins, provisioning, storage, subject and support.

## Layout

- `protobuf/contracts/<domain>/v1/*.proto`: the sources, in proto package `contracts.<domain>.v1`.
- `<domain>/protobuf/` (and `anchor/pb`, `options`): the generated Go packages, imported as `github.com/bbmumford/contracts/<domain>/protobuf`.

## Use

```sh
go get github.com/bbmumford/contracts
```

```go
import billingpb "github.com/bbmumford/contracts/billing/protobuf"

req := &billingpb.GetCustomerRequest{ /* ... */ }
```

After changing a `.proto` file, regenerate the Go code at the repository root with `buf generate` (`buf.yaml` names the `protobuf` module; `buf.gen.yaml` runs protoc-gen-go and protoc-gen-go-grpc with `module=github.com/bbmumford/contracts`), and commit the sources and the generated files together.

## Dependencies

- No other package of this estate.
- `google.golang.org/protobuf`, `google.golang.org/grpc` (the generated
  service stubs) and `google.golang.org/genproto/googleapis/api`
  (`google.api.http` annotations).

## Platforms and build

Pure Go, no cgo and no build tags; the Go code is generated by `buf generate`
(protoc-gen-go and protoc-gen-go-grpc). The module's `go` directive is
1.25.0.
